## M5 — done and merged

**M5 — Invoice output & demo polish**, built on `feature/m5-invoice-output` (off `develop`) and merged into `develop` 2026-07-03 (`--no-ff`; branch deleted). All segments landed; the exit criterion (a full stakeholder demo from seed, ending in a PDF) is met — see `docs/demo.md`. Segment plan:

- [x] **Seg 0 — Open the milestone.** Plan progress + status + this segment checklist; M4 merged into `develop` (plus the `derive.ts` NUL→`\x00` hotfix).
- [x] **Seg 1 — Invoice document.** One styled `InvoiceDocument` component; the finalized invoice renders through it on screen (the polished view) with print CSS tuned. Drafts keep the working editor.
- [x] **Seg 2 — PDF output (G9).** Playwright headless Chromium prints the same document to PDF; a "Download PDF" action on finalized invoices. `lib/pdf.ts` seam owns the browser; a bare `/print/[id]` route (shell-free, outside `(app)`) is the print surface; `/invoices/[id]/pdf` forwards the session cookie so Chromium loads it as the same user.
- [x] **Seg 3 — Org settings.** A `/settings` page (business name, from block, currency/tax/terms defaults, invoice prefix + next-number preview, footer) behind the `company.settings` capability, reached via a capability-gated sidebar link — the branding finalize snapshots. Feature folder `features/org/` (validate + tests, queries, action) mirrors the clients pattern. **Logo upload deferred (D17)** at the user's request: it'll live on Settings later, image files only; the `Asset` table + finalize's `logoAssetId` snapshot already exist, so it's additive. The `lib/assets.ts` seam ships with it, not now — the Settings page shows a "Logo — coming soon" card.
- [x] **Seg 4 — Time display format.** Org default H:MM vs decimal wired through the `duration.ts` seam (new `formatDurationAs`/`formatDurationInputAs` dispatchers) to the day view, weekly grid, running timer, and the invoice picker's unbilled hints. The preference rides on the `Actor` (resolved once in `currentActor`, so every read layer/view already has it) and is edited on the Settings page. New `timeDisplayFormat` org column (migration `20260703182745`).
- [x] **Seg 5 — Dashboard + polish.** Real post-login dashboard (`features/dashboard/` read layer aggregating time + invoices + clients; time tiles reuse `LiveDuration` so they tick; invoice slice gated on `invoice.manage`). App-segment `loading.tsx` skeleton, `error.tsx` boundary (with retry), and `not-found.tsx`. Existing empty states already consistent; no theming overhaul needed beyond the Card-based dashboard.
- [x] **Seg 6 — Full demo seed + `docs/demo.md`.** Seed v5 adds a finalized-but-unpaid EUR fixed-fee invoice (Globex ERP Migration, INV-0003) so all three lifecycle states + the dashboard's awaiting-payment tile show real data. `docs/demo.md` is the scripted ~10-minute walkthrough (setup → dashboard → timesheet/timer → work structure → settings/time-format → invoice draft → finalize → PDF), with a seed-data reference table and reset instructions.

Review-driven additions on top of segs 1–2 (all committed on the branch): invoice-document refinements (subject line above the items, "NET30"-style terms, date-first `YYYY/MM/DD` line dates); a draft **Preview** (renders the polished document stamped DRAFT, no finalize); the invoice number **pre-filled + editable on the draft**, frozen at finalize, unique-but-not-gapless (**D15**); and a **Void** correction path for finalized invoices — releases the billed time/fees back to the pool for a corrected invoice (**D16**). Recorded as full-version deferrals: **credit notes** and **emailing the invoice to client contacts at finalize**.
